TATO SLOZKA NEOBSAHUJE VE VYCHOZIM ZIPU STAZENE FOTOGRAFIE.
Ve vychozim nahledu se ilustracni fotografie nacitaji z Unsplash.
Pred nasazenim spustte v koreni projektu:
  python -m pip install pillow
  python tools/fetch_photos.py
Pripravene mistni soubory .webp pak web automaticky pouzije.
Fotografie nejsou skutecnymi realizacemi firmy.
