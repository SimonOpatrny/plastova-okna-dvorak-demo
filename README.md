# Plastová okna Dvořák – nezávazný návrh webu

Statická demo ukázka šesti stránek. Kontaktní formulář záměrně neodesílá zprávy. Fotografie z původního webu se zobrazují externě pouze v ukázce; jejich užití je nutné před schválením finálního projektu odsouhlasit. Provozní PHP backend a Google Analytics nejsou součástí tohoto HTML náhledu.
